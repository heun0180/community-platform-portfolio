# 데모 버전 살펴보기

GuildUp의 운영진 화면을 살펴볼 수 있도록 가상의 클랜원과 경기 기록을 넣은 읽기 전용 체험 커뮤니티를 만들었습니다. 최근 버전에서는 대시보드에서 확인할 인원을 찾아가는 흐름과 내전·킬내기 팀 편성을 추가했습니다.

## 체험 계정으로 로그인

- 사이트: [https://guild-up.com/](https://guild-up.com/)
- 아이디: `demo@example.com`
- 비밀번호: `cpdemo2026`

일반 로그인 화면에서 이메일과 비밀번호를 입력하면 됩니다. 체험 계정은 읽기 전용으로, 설정이나 이벤트를 변경해도 저장되지 않습니다.

## 화면에서 볼 수 있는 흐름

### 1. 체험 커뮤니티와 대시보드 열기

체험 계정으로 로그인하면 ‘내 커뮤니티’에서 준비된 커뮤니티를 열 수 있습니다. 운영 사이트의 일반 로그인 화면에서는 체험 계정 안내를 숨겼습니다. [GuildUp 서비스](https://guild-up.com/)

대시보드에서 공지와 운영진의 **처리할 일**을 볼 수 있습니다. ‘클랜 활동 없음’을 누르면 최근 경기가 없는 사람과 클랜 활동 기준을 채우지 못한 사람이 걸러진 목록이 열립니다. ‘음성 장기 미접속’에서는 해당 기간 동안 접속 기록이 없는 클랜원을 살펴볼 수 있습니다.

### 2. Discord 클랜원 명단과 게임 계정 확인

클랜원 명단에서 Discord 클랜원과 웹 회원의 연결 상태를 확인할 수 있습니다. 닉네임 규칙 화면에서는 Discord 표시명으로부터 어떤 게임 닉네임을 추출하는지 미리 볼 수 있습니다.

### 3. PUBG 활동 조회

준비된 조회 결과에서 판정별 클랜원 목록을 열어 어떤 조건으로 활동이 인정됐는지 확인합니다. ‘계정 확인 필요’로 표시된 사람과 최근에 경기는 했지만 활동 기준을 채우지 못한 사람을 구분해 볼 수 있습니다.

### 4. 킬내기

데모에서는 준비된 대회의 설정과 참가자, 순위 및 집계 결과를 살펴볼 수 있습니다. 실제 운영에서는 운영진이 개인전·듀오·스쿼드 중 하나를 고르고, 킬 점수와 순위 보너스를 정합니다.

대회가 끝났다고 바로 모든 기록을 확정하지는 않습니다. 마감 직전에 시작한 경기가 늦게 끝날 수 있기 때문입니다. 종료 시각과 경기 시작 시각을 구분하고, 결과를 수집한 뒤 점수를 계산하도록 했습니다.

### 5. PUBG 빙고

준비된 빙고판을 열어 미션과 달성 상태를 확인할 수 있습니다. 실제 운영에서는 킬·피해량처럼 경기 상세에서 확인할 수 있는 수치와 아이템 사용처럼 텔레메트리를 읽어야 하는 기록을 구분해 미션을 판정합니다. 미션 조건에 따라 봇 처치를 제외합니다.

### 6. 월간·누적 랭킹

랭킹은 커뮤니티마다 별도로 계산합니다. 이번 달과 지난달, 누적 점수를 조회할 수 있으며 동점자는 같은 순위를 갖습니다.

출석과 킬내기 우승처럼 점수가 쌓이는 이유는 변경 이력에 남습니다. 같은 대회의 보상을 다시 처리하더라도 한 번만 적립되도록 지급 건을 구분합니다.

### 7. 내전과 킬내기 팀 편성

실제 운영 화면에서는 내전에 참가할 클랜원과 시즌을 고르면 최대 100명까지 팀을 편성합니다. 팀 카드에서 평균 피해량과 범위를 비교하고, 자리를 바꾼 뒤 결과를 Discord 공유용 텍스트로 복사할 수 있습니다. 팀전 킬내기에서는 모집 중 승인된 사람을 편성해 미리 보고 대회 팀에 적용합니다.

체험 계정에서는 저장과 외부 전적 조회가 제한됩니다. 새 전적을 불러오는 팀 편성과 실제 팀 배정 적용은 운영진이 자신의 커뮤니티에서 쓰는 기능입니다.

## 데모를 만들면서 신경 쓴 부분

**경기 기록을 기능마다 다시 가져오지 않기**

킬내기와 빙고는 모두 PUBG 경기 정보를 사용합니다. 두 기능이 각각 처음부터 모든 경기를 다시 수집하면 API 호출이 많아집니다. 그래서 공통 경기 수집기를 두고, 저장된 데이터가 어떤 수준의 통계를 포함하는지 버전으로 구분했습니다. 킬·순위 정도만 있으면 되는 경우와 빙고 미션용 상세 통계까지 필요한 경우를 다르게 처리합니다.

**외부 호출 중 데이터베이스 잠금을 오래 잡지 않기**

PUBG API 응답은 예상보다 오래 걸릴 수 있습니다. 대회 생성·진행 상태 기록과 외부 수집, 집계 결과 반영을 구분해 외부 응답을 기다리는 동안 불필요한 잠금이 이어지지 않도록 했습니다.

**예약 작업과 중복 처리**

킬내기의 마감과 정산, 빙고의 자동 수집과 최종 정산은 서버가 정해진 시각에 처리합니다. 실행할 작업과 상태를 DB에 저장하고, 동일한 작업이 동시에 처리되거나 점수가 두 번 지급되지 않도록 상태 확인과 중복 방지 절차를 마련했습니다.

**체험 계정에서도 운영진 화면 보여 주기**

운영진이 확인하는 화면을 보여 주기 위해 데모 커뮤니티에 가상의 회원·이벤트·활동 기록을 준비했습니다. 체험 계정의 저장 요청은 서버에서 막고, Discord와 PUBG 클라이언트에서도 체험 세션을 확인합니다.

개발 환경에서는 체험 계정 로그인, 데모 데이터 화면과 저장 차단을 확인했습니다. 2026년 11월 27일에는 공개 사이트 응답과 배포된 화면에서 팀 편성 코드가 제공되는 것을 확인했습니다. 운영 사이트에서의 체험 계정 로그인과 실제 PUBG 전적으로 킬내기 팀을 편성해 적용하는 과정은 추가 확인이 필요합니다. [테스트와 남은 작업](05-validation.md)
