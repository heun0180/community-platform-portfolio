# 기능별 구현 내용

클랜 운영에 필요한 기능을 추가하면서 어떤 기준을 세웠는지 정리했습니다. 가입 신청과 클랜원 확인부터 경기 기록 조회, 팀 편성, 이벤트 정산까지 운영진이 화면에서 하는 일을 중심으로 소개합니다.

## 1. 로그인과 계정 연결

이메일 계정만 사용하거나 Discord 계정만 사용하는 사람 모두 서비스를 이용할 수 있도록 가입과 로그인 방식을 나눴습니다.

이메일로 가입한 사람도 나중에 Discord 계정을 연결할 수 있어야 하고, Discord로 로그인한 사용자도 자신의 서비스 계정을 유지할 수 있어야 합니다.

여기서 중요했던 점은 **이메일 주소가 비슷하거나 닉네임이 같다는 이유로 두 계정을 합치지 않는 것**이었습니다. Discord 계정 연결은 해당 사용자의 고유 ID를 기준으로 처리하고, 이미 다른 계정에 연결돼 있다면 중복 연결되지 않도록 합니다.

이메일 인증과 로그인 수단 관리도 같은 계정 흐름 안에서 다루고 있습니다. 가입과 비밀번호 재설정에서는 흔히 쓰이는 비밀번호를 거르고, Discord 연결을 해제할 때 비밀번호 확인에 반복해서 실패하면 시도를 제한합니다.

## 2. 커뮤니티 생성과 가입

커뮤니티마다 운영 방식이 다르기 때문에 처음부터 다음 기준을 정했습니다.

- 커뮤니티는 기본적으로 비공개
- 하나의 커뮤니티는 하나의 게임을 선택
- 초대 링크와 가입 신청을 지원하고, 운영진이 가입 신청을 승인하거나 거절
- 권한은 OWNER / ADMIN / MEMBER로 구분

운영진이 다른 회원의 권한을 변경할 수 있더라도, 일반 회원의 활동 정보가 운영진 권한을 바꾸는 데 쓰이지 않도록 구분했습니다.

같은 사용자라도 커뮤니티별 역할이 달라질 수 있습니다. 회원 조회와 수정은 해당 커뮤니티 안에서 처리하고, 가입·탈퇴·추방과 같은 상태 변경은 이력으로 남깁니다.

## 3. Discord 서버와 클랜원 동기화

Discord 서버의 회원을 가져오는 일과 웹서비스 회원으로 등록하는 일은 별개입니다.

예를 들어 Discord 서버에 들어와 있어도 아직 플랫폼 계정이 없을 수 있고, 플랫폼 계정이 있어도 특정 커뮤니티에 가입하지 않았을 수 있습니다. 이 둘을 하나로 처리하면 권한 관리가 꼬일 수 있습니다.

그래서 Discord에서는 **서버 소속과 지정 역할**을 확인하고, 플랫폼에서는 **서비스 계정과 커뮤니티 회원 정보**를 따로 관리합니다.

### Discord 계정으로 클랜원 연결

로그인한 사람의 Discord ID와 동기화된 클랜원의 Discord ID가 정확히 일치하면 해당 회원을 연결합니다.

이때 다음 조건을 함께 확인합니다.

- 현재 커뮤니티에 연결된 Discord 서버의 클랜원인지
- 지정된 역할이 확인된 활성 클랜원인지
- 이미 해당 커뮤니티 회원으로 등록되어 있지는 않은지
- 기존 운영진 역할이나 탈퇴·추방 기록을 변경하게 되지는 않는지

닉네임 변경과 중복 이름 문제를 피하기 위한 방식입니다. 운영 전환 때 실제 Discord 서버의 클랜원 목록을 다시 가져왔고, 운영 기록에 동기화 성공이 남았습니다.

클랜원 명단은 Discord 서버 프로필 사진을 우선 표시하고, 서버 사진이 없으면 개인 프로필 사진을 사용합니다. 웹 서비스 가입 여부와 앱 회원 관리 탭은 운영진 화면에 표시합니다.

## 4. PUBG 게임 구분

지금 다루는 게임은 PUBG지만 Kakao와 Steam을 같은 데이터로 취급할 수는 없습니다. PUBG API를 호출할 때도 플랫폼을 구분해야 하기 때문입니다.

커뮤니티를 만들 때 게임과 플랫폼을 선택할 수 있게 했습니다. 커뮤니티와 회원이 공통으로 쓰는 정보는 그대로 두고, PUBG 계정이나 경기 기록처럼 게임에 따라 달라지는 데이터는 PUBG 모듈에서 관리합니다.

## 5. 게임 닉네임 추출과 PUBG 계정 연결

클랜에서는 Discord 닉네임을 일정한 형식으로 사용하는 경우가 있습니다.

예를 들어 `애플/93/sa-gwa`라면 마지막 항목인 `sa-gwa`가 게임 닉네임입니다. 운영진이 예시를 입력하면 구분자와 항목 위치를 바탕으로 규칙을 만들고, 실제 적용 전에 추출 결과를 미리 볼 수 있게 했습니다.

추출한 닉네임은 PUBG API에서 계정을 찾는 데 사용합니다. 빙고에서 쓸 PUBG 계정은 확인된 Discord 정보와 닉네임 규칙을 바탕으로 자동 연결하거나, 회원이 게임 닉네임을 직접 입력해 연결할 수 있습니다.

## 6. PUBG 클랜 활동 조회

운영진은 조회 기간, 같은 팀에서 플레이한 최소 클랜원 수, 필요한 경기 수를 설정할 수 있습니다. 예를 들어 최근 14일 동안 본인을 포함한 클랜원 2명 이상이 같은 팀에서 3경기 이상 플레이했는지 확인할 수 있습니다.

경기 수집은 백그라운드에서 진행하고, 조회에 사용한 기준과 회원별 판정 결과를 남깁니다. 계정을 찾지 못하거나 외부 API 오류로 기록이 부족할 때는 확인이 필요한 상태로 표시합니다. 운영자는 결과 화면에서 판정 근거가 된 경기를 살펴볼 수 있습니다.

## 7. PUBG 킬내기와 빙고

킬내기는 정해진 기간 동안에 시작한 경기의 킬과 등수를 바탕으로 개인전·팀전 순위를 계산합니다. 운영진은 대회를 열고 참가자와 팀을 관리할 수 있습니다. 종료 후 최종 결과를 집계하고, 경기 참여 조건을 충족한 우승자에게 랭킹 점수를 지급합니다.

빙고는 운영진이 정한 미션을 참가자가 PUBG 경기에서 달성하는 방식입니다. 경기 상세와 텔레메트리에서 미션의 조건을 확인하고, 필요한 항목은 사람을 상대로 달성한 기록만 집계합니다. 참가자는 자기 빙고판과 미션을 인정받은 경기를 볼 수 있습니다. 일부 미션에는 킬내기 우승 결과도 반영됩니다.

## 8. 월간·누적 랭킹

커뮤니티마다 랭킹을 따로 보여 줍니다. 기본 화면은 서울 시간 기준 이번 달 랭킹이고, 지난달과 누적 순위도 볼 수 있습니다.

점수가 바뀔 때마다 변경 이유와 이력을 남깁니다. 킬내기 보상을 다시 처리해도 같은 보상이 두 번 쌓이지 않도록, 점수를 지급한 근거를 함께 기록합니다.

## 9. Discord 실시간 반영과 음성 활동

Discord 서버의 멤버 입퇴장, 역할과 닉네임 변경을 받아 클랜원 명부를 갱신합니다. 앱이 재시작되거나 Discord 세션이 새로 만들어지면 서버 목록을 다시 가져와 놓친 변경을 보완합니다. 클랜 역할을 잃은 경우에는 운영진이 명부에서 이탈을 확인할 수 있고, 서비스 회원 자격은 유지합니다.

운영진은 서비스 닉네임과 Discord 닉네임 중 회원 화면에 표시할 이름을 고를 수 있습니다. 경기 조회와 이벤트 집계에는 PUBG에서 확인한 게임 계정 정보를 사용합니다.

음성 활동은 활성 클랜원의 채널 입장·퇴장·이동을 세션으로 기록합니다. 운영진은 기간별 누적 시간과 채널별 기록을 확인할 수 있습니다.

## 10. 커뮤니티 공지와 출석체크

운영진은 공지를 작성하고 중요한 공지를 고정할 수 있습니다. 회원은 대시보드에서 고정·최신 공지와 새 공지 여부를 확인합니다. 작성 중인 내용은 브라우저에 임시 저장해 화면을 벗어난 뒤에도 이어서 쓸 수 있습니다.

회원은 랭킹 화면에서 직접 출석하고 서울 시간 기준 하루에 한 번 1점을 받습니다. 같은 날에 여러 번 누르거나 요청이 겹쳐도 한 번만 반영되도록 했습니다.

## 11. 경기 수집 공통화와 통계 버전

킬내기와 빙고는 같은 PUBG 경기 데이터를 사용하지만 필요한 통계는 다릅니다. 킬내기에는 주로 킬 수와 순위가 필요하고, 빙고에는 피해량·부활·아이템 사용·봇 처치 구분 등 더 자세한 정보가 필요합니다.

두 기능이 각각 외부 API를 호출하지 않도록 공통 수집기를 사용합니다. 경기 상세를 저장할 때 통계 버전도 기록해, 빙고에 필요한 데이터가 없는 경기만 추가로 수집하도록 했습니다. 텔레메트리는 경기 단위로 읽고 계정별 결과를 보관합니다.

## 12. 운영진 대시보드

운영진은 대시보드의 **처리할 일**에서 가입 신청, 커뮤니티 미참여, PUBG 계정 확인 필요, 클랜 활동 없음, 음성 장기 미접속과 Discord 연결 문제를 권한에 따라 확인합니다. 계정 확인 필요·클랜 활동 없음·음성 장기 미접속 항목을 누르면 조건에 해당하는 클랜원 목록으로 바로 이동합니다.

대시보드의 ‘클랜 활동 없음’에는 최근 경기가 없는 사람과 경기는 했지만 클랜 활동 기준을 채우지 못한 사람이 포함됩니다. 활동 조회 화면에서는 두 판정을 각각 확인할 수 있고, 대상이 0명인 판정도 필터에 남겨 둡니다.

## 13. 내전과 킬내기 팀 편성

내전에서는 활성 클랜원 중 최대 100명을 고르고 이번 시즌·지난 시즌·두 시즌 합산 중 하나를 선택합니다. PUBG 3인칭 스쿼드의 경기당 평균 피해량으로 팀을 나눕니다. 각 팀의 평균과 팀원 간 피해량 범위가 표시되며, 두 사람의 자리를 바꾼 뒤 결과를 Discord용 텍스트로 복사할 수 있습니다.

팀전 킬내기에서는 모집 중 승인된 참가자를 대상으로 같은 기준을 적용합니다. 운영진이 팀 수와 시즌을 고른 뒤 미리보기에서 자리를 바꾸고, 확인 창에서 적용하면 참가자 전체가 새 배치로 바뀝니다. 미리보기를 만든 뒤 승인 참가자가 달라졌다면 새로 편성하도록 안내합니다.

## 14. 읽기 전용 데모 커뮤니티

가상의 클랜원과 경기 기록을 미리 넣어 운영진 화면을 살펴볼 수 있게 했습니다. 체험 세션에서는 서버가 저장 요청과 외부 연동 요청을 제한합니다. 대시보드, 클랜원 명단, 활동 기록, 킬내기 결과, 빙고판, 랭킹은 준비해 둔 데이터를 보여 줍니다.
