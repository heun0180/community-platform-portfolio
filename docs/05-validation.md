# 테스트와 남은 작업

## 테스트할 때 중요하게 보는 부분

기능 하나가 정상적으로 동작하는 것만큼, **잘못된 입력이나 예상하지 못한 상황에서도 기존 데이터가 망가지지 않는지** 확인하는 것이 중요하다고 생각합니다.

예를 들어 Discord 회원을 연결할 때는 ID가 일치하는 경우만 보지 않습니다. 이미 가입한 회원인지, 운영진 권한을 갖고 있는지, 탈퇴·추방한 이력이 있는지도 함께 확인해야 합니다.

자동 테스트에서는 이러한 분기와 예외를 확인하고 있습니다. 다만 외부 시스템이 개입하는 기능은 로컬 테스트와 실제 Discord 서버에서의 동작을 별도로 확인해야 합니다.

## 앞으로 확인할 항목

| 기능 | 확인할 내용 |
| --- | --- |
| 로그인 | 이메일 인증, Discord 로그인·연결, 중복 연결 방지 |
| 커뮤니티 | 비공개 정책, 승인 흐름, OWNER/ADMIN/MEMBER 권한 |
| Discord 동기화 | 봇 권한과 역할, 실제 서버 멤버 조회 및 변경 반영 |
| 회원 연결 | 고유 ID 일치, 탈퇴·추방 회원의 재연결 방지 |
| 데이터 분리 | 한 커뮤니티에서 다른 커뮤니티의 회원 정보를 읽거나 수정할 수 없는지 |
| PUBG 연동 | Kakao/Steam 구분, 게임 계정과 경기 데이터 저장 |
| 활동 판정 | 기간·인원 기준, 계정 미확인, API 조회 실패 처리 |
| 운영 조치 | 중복 실행, 권한 부족, 외부 요청 결과가 불명확한 상황 |

## 아직 보완할 부분

현재는 인증과 커뮤니티 관리, Discord 연동을 중심으로 기능을 개발하고 있습니다. 실제 Discord 서버와 연결해 보는 과정, 게임 데이터 수집, 커뮤니티 간 데이터 분리 검증은 계속 보완할 부분입니다.

기능이 완성되면 화면만 첨부하기보다 **어떤 상황에서 문제가 발생했고 어떤 변경으로 해결했는지**를 코드와 함께 남길 계획입니다. 성능 개선이나 외부 API 호출 감소 효과도 실제 측정한 결과가 생겼을 때만 기록하려고 합니다.
